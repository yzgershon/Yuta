# Repository media

The README combines generated concept photographs from the initial preview with captures of Yuta's current interface. The Home, Today, and compact-player captures are the reference for the shipped layout; the concept photographs are not exact screenshots of 0.2.0.

| Asset | Origin |
| --- | --- |
| `images/yuta-hero.png` | Built-in image generation, guided by the real Home capture. |
| `images/yuta-detail.png` | Built-in image generation, guided by a native music-notch render and the hero art direction. |
| `images/home.png` | Actual `ui/` rendered at 2x pixel density with fictional content. |
| `images/today.png` | Actual `ui/` rendered at 2x pixel density with fictional content and a deterministic clock. |
| `images/media.png` | Actual 400 × 144 compact player rendered at 2x pixel density with the same fictional track. |

Run `npm.cmd run docs:capture` on Windows with Microsoft Edge installed to regenerate the interface captures. The script uses an isolated synthetic bridge and does not access a Windows profile, listening history, clipboard, or personal files. The small sample album illustration is original procedural artwork. Generated hero/detail imagery was produced with the built-in image generation tool, not the API/CLI fallback.

The original Yuta artwork follows the repository's all-rights-reserved notice. Product names in captures identify compatible apps and do not imply affiliation.

## Hero generation prompt

Use case: product-mockup. Asset type: high-end GitHub repository hero for Yuta, a Windows desktop notch utility. Create one exceptionally refined wide 16:9 product presentation at 2560x1440 or highest available landscape resolution. The supplied reference is Yuta's real Home interface. Preserve its composition and controls: Home, Today, Stats, Wallpaper tabs; clipboard on the left; compact Spotify player and app shortcuts on the right; charcoal #101219 surfaces; violet #9b80ff accent. This is a desktop app, not a mobile app. Compose a clean, nearly front-facing thin dark desktop monitor/display, tightly framed around its upper half, with this interface attached at the top center below the webcam, shaped as a smooth black notch with concave shoulders and rounded bottom corners. The UI should be clearly recognizable and legible, close to the reference, without invented functions. Surround it with an elegant midnight-violet abstract wallpaper of soft satin-like light planes and a subtle warm horizon, NOT a Windows logo or stock wallpaper. Refined controlled studio light, physically plausible glass, very faint reflections, matte graphite edge, realistic restrained depth, no noisy glow or clutter. Leave generous dark negative space at the left and upper left for the exact text 'Yuta' in large crisp off-white geometric sans serif, and underneath in smaller type the exact text 'Your Windows essentials. Within reach.' The monitor and app take the right two thirds and lower center. Editorial tech product photography, precise typography, beautiful scale and spacing. No people, no phones, no Apple logo, no anime character, no cables, no watermarks, no badge grid, no tiny slogans. One finished cohesive product photograph, no collage.
