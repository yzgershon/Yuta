# Security

Report suspected vulnerabilities privately using [GitHub's private vulnerability reporting](https://github.com/yzgershon/Yuta/security/advisories/new).

Include a minimal reproduction, affected revision, Windows version, and the security impact. Use synthetic data and omit credentials, clipboard history, and unrelated personal files. Do not open a public issue containing exploit details or private data.

If the private reporting form is unavailable, open an issue asking for a private contact route without including vulnerability details.

Yuta is an early source preview. Security fixes currently target the latest `main` revision; there is no long-term support branch or guaranteed response time.
